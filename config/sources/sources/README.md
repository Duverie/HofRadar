# HofRadar Suchquellen

Hier werden später alle Suchquellen eingebunden.

## Schweiz 🇨🇭

Geplante Quellen:

- Immobilienportale
- Landwirtschaftliche Angebote
- Tierwelt
- Schweizer Bauer
- BauernZeitung
- regionale Anzeigen

## Elsass 🇫🇷

Geplante Quellen:

- Immobilienportale
- regionale Makler
- landwirtschaftliche Angebote
- Zeitungsanzeigen

## Südbaden 🇩🇪

Geplante Quellen:

- Immobilienportale
- regionale Anbieter
- Kleinanzeigen

## Bewertung jeder Quelle

Jede gefundene Immobilie wird später geprüft nach:

- Preis
- Grundstücksgrösse
- Pferdehaltung
- Stall/Scheune
- Wohnmöglichkeiten
- Entfernung
